# Architecture Guide Demo

Небольшой прототип цифрового архитектурного гида. Объект демо — Дом Севастьянова в Екатеринбурге.

Сценарий: QR-код → страница архитектурного объекта → фотография + короткая информация.

**GitHub Pages:** https://maksimkovalyukevg.github.io/architecture-guide-demo/

`qr-code.png` содержит QR на публичный сайт GitHub Pages, а не на репозиторий.

Фото не было приложено: сейчас используется временный визуальный placeholder `assets/building-placeholder.svg`. Он не изображает реальное здание.

## Как изменить страницу

- Название: замените текст в `<h1>` и `<title>` файла `index.html`.
- Описание: замените текст в `<p>` файла `index.html`.
- Фотография: добавьте файл `assets/building.jpg`, укажите `src="./assets/building.jpg"` в `<img>` и обновите `alt`, `width`, `height` под новое изображение.

Сделайте commit и push в `main`: GitHub Pages обновит сайт из корня ветки. URL и QR-код сохранятся.

Страница использует только HTML и CSS. Движется только изображение; при включённом уменьшении движения в настройках устройства анимация отключается. Backend, JavaScript, внешние шрифты и сборка не нужны.
